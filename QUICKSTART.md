# TRADEPRO AI - Quick Start Guide

Welcome to TRADEPRO AI! This guide will help you get started quickly.

## 🚀 Getting Started in 5 Minutes

### 1. Login
1. Navigate to: `https://your-app-url.com/login`
2. Use the demo credentials:
   - **Email**: `admin@tradepro.com`
   - **Password**: `admin123`
3. Click "Sign In"

### 2. Connect Your First Broker
1. Click on **Settings** in the sidebar
2. Click **Add Broker**
3. Select a broker from the dropdown (e.g., Zerodha, Binance)
4. Enter your API credentials:
   - API Key
   - API Secret
5. Click **Connect Broker**

### 3. Create Your First Strategy
1. Click on **Strategies** in the sidebar
2. Click **New Strategy**
3. Enter a strategy name (e.g., "My RSI Strategy")
4. Add nodes from the library:
   - Drag **RSI** indicator
   - Drag **Greater Than** condition
   - Drag **Buy** action
5. Connect the nodes
6. Click **Save Strategy**

### 4. Place Your First Order
1. Click on **Trading Terminal** in the sidebar
2. Select a symbol from the watchlist (e.g., AAPL)
3. Choose order type:
   - **Market**: Execute immediately at current price
   - **Limit**: Set your desired price
4. Enter quantity (e.g., 10 shares)
5. Click **Place Buy Order**

### 5. Monitor Your Portfolio
1. Click on **Dashboard** in the sidebar
2. View your portfolio metrics:
   - Portfolio Value
   - Total P&L
   - Active Strategies
   - Win Rate
3. Check **Recent Orders** section
4. Navigate to **Positions** to see open positions
